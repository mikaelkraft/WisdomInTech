## 🌟 About

**Wisdom In Tech** is a modern, high-performance web platform designed to present my technical journey, production software, and engineering philosophy. It combines an interactive project showcase, a full-featured technical publishing engine, and custom administrative tools into a cohesive, responsive experience.

---

## ✨ Key Highlights

- **🚀 Project Showcase**  
  Filterable catalog of featured software solutions, full-stack applications, and open-source packages with live demos, code repositories, and architecture breakdowns.

- **✍️ Technical Blog & Knowledge Hub**  
  A built-in publishing platform for technical deep dives, system design write-ups, and developer tutorials featuring Markdown rendering, syntax highlighting, and reading-time metrics.

- **🔍 Full-Text Search & Discovery**  
  Fast search powered by PostgreSQL `tsvector` weighted ranking and highlighted result snippets, coupled with an automated related-posts recommendation engine.

- **🎨 Dynamic Design System**  
  Crafted with Tailwind CSS and Framer Motion, featuring smooth transitions, dark/light theme versatility, fluid typography, and mobile-first responsiveness.

- **⚡ Dual-Mode Full-Stack Architecture**  
  Engineered for flexibility: operates seamlessly with serverless Supabase endpoints or a dedicated Node.js/Express API with direct PostgreSQL pooling.
